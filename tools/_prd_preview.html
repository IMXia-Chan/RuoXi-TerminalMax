1. 文档说明

1.1 目的

本文定义 ConMarn 的产品边界、功能需求、非功能需求与验收标准，作为开发、测试与后续版本规划的共同依据。

1.2 阅读对象

产品、客户端开发、服务端开发、测试、安全评审。

1.3 需求编号规则

前缀含义
FR-域-序号功能需求（Functional Requirement）
NFR-序号非功能需求
SEC-序号安全需求
DATA-序号数据与隐私需求

每条需求包含"描述—约束—验收"三部分。无验收标准的需求不进入范围。

1.4 数据标注

·【实测】：在目标设备上测得，附测量条件；
·【测算】：假设推演；
·【待核】：需外部数据支撑，暂不做数值断言。

2. 产品定义

2.1 一句话定义

ConMarn 是一套将模型推理、语音、形象、记忆与外设控制收敛到用户自有设备上运行的智能体系统；在无网络条件下保持完整可用，在网络可用时可将外设任务派发至用户自己的其他设备。

2.2 产品形态

形态载体职责
宿主安卓手机（当前唯一实测形态）判断、记忆、语音、形象、任务编排
边节点个人电脑（当前唯一实测形态）执行宿主派发的设备操作任务并回执
云节点使用者自填密钥的第三方模型接口可选的推理兜底，默认关闭

2.3 范围（In Scope）

1. 端侧模型推理与固定前缀快照管理；
2. 唤醒、语音识别、语音合成的本地闭环；
3. 三维形象渲染与动作驱动；
4. 对话记忆、经验积累与研究资料的结构化存储；
5. 外设能力契约的定义、派发、回执与核验；
6. 多任务并行的工作台；
7. 权限与风险控制；
8. 电脑端节点的安装与运行。

2.4 非范围（Out of Scope）

1. 通用操作系统级替代（不做桌面系统、不做 ROM）；
2. 面向陌生设备的静默控制（配对必须物理在场）；
3. 大规模云服务运营（项目方不承担服务器成本）；
4. 跨品牌设备的零成本接入（每接入一家为企业独立集成）；
5. 真人形象的未授权复制。

3. 用户与场景

3.1 用户角色

角色描述关键诉求
宿主使用者手机的实际持有人断网可用、数据不出机、可自行定义人格
边节点授权者提供电脑等设备接入的人明确授权、可随时断开、操作可核验
开发者安装并可能修改代码的人可读源码、可扩展能力、可复现

3.2 核心场景

S1 无网络下的持续对话。 用户在无网络环境唤醒并对话，全部链路在端侧完成。

S2 跨设备操作。 用户通过一句话要求电脑完成文件整理、窗口切换或界面点击，宿主派发任务并核验回执。

S3 长任务并行。 用户在同一时间提出多件事，工作台并行执行，互不干扰，可单独停止。

S4 危险操作确认。 涉及资金、身份或不可逆操作时，系统中断执行并要求二次确认。

S5 用户自定义人格。 用户自行设定助手的语气、性格与形象，系统不预设立场。

4. 系统架构

4.1 逻辑结构

宿主（手机）
├── 判断层：端侧模型推理 + 工具调度 + 风险判断
├── 感知层：唤醒 / 语音识别 / 视觉（按需）
├── 表达层：语音合成 / 三维形象 / 界面
├── 记忆层：对话记忆 / 经验库 / 资料库
└── 契约层：能力登记 / 任务派发 / 回执核验
        │
        ├── 边节点：电脑（Windows 已实测）
        └── 云节点：第三方模型接口（可选、默认关闭）

4.2 关键设计约束

约束含义违反判定
端侧优先能在本机完成的推理不离开本机任何默认上传路径均视为缺陷
数据单向截图、音频不离开宿主出现上传即阻断
契约稳定新增设备不修改宿主代码需改宿主即判定契约失效
证据优先不信任"操作成功"返回值无证据的下结论即为缺陷

5. 功能需求

5.1 唤醒与听觉（FR-EAR）

编号需求约束验收
FR-EAR-01支持固定唤醒词唤醒唤醒词由用户在设置中启用，默认关闭安静环境下连续 20 次唤醒，误触发 0 次
FR-EAR-02唤醒后进入一次听写会话会话有明确开始与结束，结束后自动关闭麦克风会话结束后麦克风占用为 0
FR-EAR-03语音识别全程本地运行不依赖网络飞行模式下识别可用
FR-EAR-04合成播放期间禁止采集半双工闸挂在合成完成回调播放期间无自激录音
FR-EAR-05后台语音需前台服务保障使用麦克风类型前台服务后台录音可获取有效音频，非静音

已知问题基线：部分机型在同音词上存在误触发；该问题记录在案，不作为本版本验收阻塞项。

5.2 语音输出（FR-TTS）

编号需求约束验收
FR-TTS-01语音合成本地完成不依赖网络飞行模式可合成
FR-TTS-02合成完成必须有结束信号无回调时按硬超时收尾任意合成在超时内释放半双工闸
FR-TTS-03语速、音高可调参数持久化重启后保持

5.3 对话与推理（FR-DIA）

编号需求约束验收
FR-DIA-01端侧模型完成主对话默认路由为端侧断网时对话正常
FR-DIA-02云端为可选兜底未填密钥不启用；转发前显式提示未配置密钥时无任何外发请求
FR-DIA-03对话上下文按会话隔离并行任务不得串话两个并行会话各自上下文独立
FR-DIA-04工具调用需参数校验非法参数不执行构造非法参数返回明确错误

5.4 端侧模型管理（FR-MDL）

编号需求约束验收
FR-MDL-01固定前缀计算结果持久化快照与模型版本绑定校验版本不匹配时拒绝加载并回退冷算
FR-MDL-02冷启动优先恢复快照恢复失败自动降级恢复耗时显著低于冷算【实测：434 ms 对 685,325 ms】
FR-MDL-03内存不足时分级降级先降模型档位，再禁用视觉低内存机型可完成一次对话
FR-MDL-04温度过高时限流触发阈值与恢复策略可配置高温下不出现无响应挂死

5.5 形象与动作（FR-AVA）

编号需求约束验收
FR-AVA-01三维形象在宿主内渲染不依赖专用硬件中端机型可稳定渲染
FR-AVA-02动作库可扩展动作文件与代码分离新增动作不修改宿主代码
FR-AVA-03语气可映射为动作映射规则可配置同一语句在不同语气下触发不同动作
FR-AVA-04等待动作必须有硬超时不允许无限等待超时后恢复默认状态

5.6 记忆与知识（FR-MEM）

编号需求约束验收
FR-MEM-01对话记忆本地存储单文件写入需原子性断电后文件不损坏
FR-MEM-02经验库按事件记录可检索、可导出检索命中既定样例
FR-MEM-03资料库支持归档与恢复删除为可确认的显式操作归档后可恢复，删除后不可恢复且有二次确认

5.7 外设与契约（FR-EXT）

编号需求约束验收
FR-EXT-01设备以能力清单自述宿主不预置设备类型新增设备类型不改宿主
FR-EXT-02任务必须回执无回执视为失败拔线场景判定为失败而非成功
FR-EXT-03指令携带签名与序号防重放重放旧序号被拒绝
FR-EXT-04未登记能力不可调用能力白名单越权调用被拒绝并记账
FR-EXT-05操作结果需屏幕证据无证据不定性三态输出：成功/失败/无法判定

5.8 工作台（FR-WB）

编号需求约束验收
FR-WB-01多任务并行执行任务间上下文隔离两个任务并行时输出不串
FR-WB-02单任务可停止且不影响其他令牌为进程级，不随界面重建丢失停止 A 后 B 继续运行
FR-WB-03任务状态以持久记录为准结束前重读状态已归档任务不被运行结果覆盖
FR-WB-04子任务有独立记忆视图不得读取全局最近记录并行时子任务不引用他人上下文

5.9 安全与权限（SEC）

编号需求约束验收
SEC-01配对须物理在场一次性码 + 被控端显式确认无静默接管路径
SEC-02危险操作二次确认资金、身份、不可逆操作单层放行不通过
SEC-03应用启动与敏感操作可启用生物识别缺权限时不得静默降级无权限时明确提示
SEC-04云端总闸关闭时全域生效包含网页请求与外部链接闸关闭时无外发请求
SEC-05外部内容不得改写风险词表词表本地固定注入内容无法改变判定

5.10 电脑端（FR-PC）

编号需求约束验收
FR-PC-01单一程序完成安装与启动无附加运行环境依赖干净系统可直接运行
FR-PC-02支持后台服务模式不显示窗口无界面进程可提供服务
FR-PC-03配对状态可在界面查看与断开断开为立即生效断开后旧凭证失效
FR-PC-04运行配置与用户数据分离不随程序升级丢失覆盖安装后配对保留

5.11 可观测性（FR-OBS）

编号需求约束验收
FR-OBS-01关键链路写日志不含配对码明文与密钥日志扫描无敏感字段
FR-OBS-02崩溃现场可留存下次启动可读取崩溃后可定位到函数

6. 非功能需求

编号需求指标说明
NFR-01唤醒到开始响应目标 1 秒内端侧链路，不含模型生成
NFR-02快照恢复目标 2 秒内【实测：1,014 ms】
NFR-03断网可用全部核心功能可用云端功能除外
NFR-04常驻内存空闲状态可控以实测基线为准，不设未经测量的硬指标
NFR-05发热持续对话不触发系统降频挂死高温时降级而非无响应
NFR-06兼容性覆盖高、中、低内存三档机型低内存档功能可裁剪
NFR-07安装门槛非开发者 30 分钟内完成首次对话安装说明与自检
NFR-08可验证性数据流向可通过阅读源码验证核心代码开源

7. 数据与隐私

7.1 数据分类

级别数据存储位置出机条件
L1 禁止出机屏幕截图、摄像头帧、原始音频仅内存，即时丢弃永不
L2 本地持久对话记忆、经验库、资料库、形象与声音素材设备本地用户导出时
L3 可出机用户请求的文本（仅在用户启用云端兜底时）内存显式启用 + 提示

7.2 数据需求

编号需求
DATA-01云端总闸默认关闭，关闭时所有外发路径一并停止
DATA-02任何外发行为在界面上可查、可关
DATA-03记忆与资料支持导出与彻底删除
DATA-04删除操作需二次确认，且不可恢复

8. 外设契约接口规格（摘要）

要素规定
能力清单由边节点自述，包含能力名、参数、风险等级
调用宿主按清单派发，携带签名与递增序号
回执必须包含执行结果与可核验证据
失败无回执、签名不符、序号重放一律判定失败
扩展新增能力通过清单声明，不改宿主判断逻辑

9. 版本规划

版本目标关键内容
当前可用性全链路真机可用、任务可靠性
近期覆盖与门槛机型覆盖、安装自检、失败集锦公开
中期交互升级全双工语音、动作生成、更多外设类型
远期终端形态换外设不改宿主、换模型不改宿主、换宿主不丢资产

10. 风险与未决项

编号问题影响处置
R-01端侧算力与发热限制长任务体验温度调度 + 限流
R-02长链路多步任务缺执行器与回滚可靠性拆分任务、显式失败
R-03局域网传输为明文加签名安全已知缺口，列入后续版本
R-04坐标点击在无控件名场景依赖视觉比对准确率三态输出，无证据不定性
R-05同音词误唤醒干扰记录在案，持续优化
R-06真人形象与声音素材的授权边界合规仅支持本人或已授权素材
R-07系统级能力的获取受厂商限制能力边界不做越权方案

11. 附录

11.1 术语

术语含义
宿主承载判断与记忆的设备，当前为安卓手机
边节点执行宿主派发任务的外部设备
能力契约设备自述能力 + 强制回执的统一接口约定
前缀快照固定提示词与工具表的计算结果持久化文件
半双工闸保证合成播放期间不采集音频的互斥控制

11.2 实测基线

指标数值条件
固定前缀规模约 4,889 词当前系统提示词与工具表
前缀首次计算685,325 ms中端安卓机，冷启动
快照恢复434 ms / 1,014 ms两次不同条件下的实测值
快照体积764.6 MB—
安卓发布包体积约 73 MBrelease，含端侧推理库

以上数值随模型与机型变化，引用时须同时给出条件。
