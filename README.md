# 若息 · Terminal Max

把 Android 手机变成电脑的 **触控板 + 远程桌面 + 摄像头/麦克风 + 文件中转站**,通过 **Wi-Fi 局域网**在手机与电脑之间双向连接、互传。

> **个人私有项目,未开源。** 此仓库仅作代码备份与自用,不对外提供使用、修改、再分发许可。

> **只在你自己可信的 Wi-Fi 下使用。** 它能把电脑的鼠标/屏幕/摄像头/麦克风交给手机、能双向传文件——
> 权限很大,务必只在自家或公司可信网络里用,别在公共 Wi-Fi / 陌生热点上开。
> 配对种子、二维码、恢复码就是你的「钥匙」,**不要截图、不要发给任何人**。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 触控板 | 手机触摸控制电脑光标(移动/点击/滚轮/拖拽/右键),灵敏度可调 |
| 屏幕镜像 | 手机实时看到电脑画面,点哪操作哪;三档画质(流畅/均衡/高清) |
| 文本输入 | 手机打字直接打到电脑当前焦点(支持中文/emoji) |
| 摄像头 → 虚拟摄像头 | 手机摄像头画面实时变为电脑的「摄像头」(OBS/会议软件可识别) |
| 麦克风 → 虚拟麦克风 | 手机麦克风声音实时变为电脑的「麦克风」 |
| 中转站 / 文件互传 | 手机⇄电脑双向传任意文件;手机任意 App 点「分享」即可直传电脑 |
| 免码续连 | 掉线/重启后自动静默重连,不必每次重新配对 |
| 开屏动画 | 启动时「RuoXi → XChan OS」开屏(纯装饰) |

## 安全设计

| 层 | 机制 |
| --- | --- |
| 电脑端登录 PIN | 打开电脑前端要先输 6 位 PIN(首次运行自己设置) |
| 动态配对码 | 手机一连上,电脑显示 6 位随机码(每次连接都变) |
| TOTP 动态码 | 配对码通过后,双方用同一把密钥 + 当前时间各自算出 6 位动态码自动校验 |
| 带外传种子 | 首次配对密钥用二维码从电脑传到手机(手机扫码) |
| 一次性恢复码 | 首次配对显示一次 8 位码,手机卸载/丢失后凭它重新配对,用一次即作废 |
| 免码续连(带锁屏校验) | resume token 随机 128 位、加密存盘、绑定手机锁屏;锁着屏时凭证不可用 |
| 防暴力破解 | 连续 3 次 TOTP 码错误 → 锁定,时长指数翻倍(30s→60s→120s…) |
| 空闲超时 | 控制模式 60 秒无操作自动断开 |
| 本地加密 | 密钥、恢复码用 Windows DPAPI 加密落盘(绑定当前 Windows 账户),不存明文 |
| 防伪造/重放 | 每条控制指令带 HMAC-SHA256 签名 + 递增序号 |

全程局域网 + 本地密钥,不依赖任何云端 / 邮箱 / 发信服务。

## 目录结构

```
phone-touchpad/
├── pc-server/
│   ├── server.py      # 电脑端服务(认证 + TOTP + 鼠标/屏幕/文本/文件/媒体)
│   ├── media.py       # 媒体帧收发(摄像头/麦克风虚拟设备)
│   ├── files.py       # 文件互传(上传接收,分帧 + SHA256 校验)
│   ├── secret.json    # 首次配对生成(种子+恢复码,DPAPI 加密,不入库)
│   └── master.json    # 登录 PIN 校验值(首次运行生成,不入库)
└── app/               # Android App(Android Studio 工程)
```

## 一、电脑端

1. 装 Python 3(没有就去 [python.org](https://www.python.org),装时勾选 Add to PATH)。
2. 装依赖:
   ```bash
   pip install segno pillow
   ```
   - 没装 `segno`:二维码不显示,退化成手动抄 32 位种子,其余功能正常。
   - 没装 `pillow`:屏幕镜像不可用,触控板/文本输入仍正常。
   - 摄像头虚拟设备另需 OBS 虚拟摄像头(或 pyvirtualcam);麦克风虚拟设备另需 VB-Cable。
3. 运行:
   ```bash
   python pc-server/server.py
   ```
   首次运行会让你设置 6 位登录 PIN,之后每次打开都要输这个 PIN。
   > Windows 下非管理员会自动申请一次提权(UAC)。**建议以管理员身份运行**,否则手机控制不了那些以管理员打开的窗口(如联想电脑管家)——这是 Windows 权限隔离(UIPI),不是 bug。
4. 界面顶部显示本机 `IP:9527`,手机端填这个 IP。

> 后台静默模式:`pythonw server.py --background`(开机计划任务 `PhoneTouchpadBG` 自启,不弹 UAC)。

## 二、手机端

1. 用 Android Studio 打开工程根目录,连手机点 `Run` 安装(或 `gradlew assembleDebug` 打 APK)。
2. 手机和电脑连**同一个 Wi-Fi**。
3. 打开 App → 点「扫描」自动发现电脑(UDP 广播,不用手输 IP)→ 自动连上。
   > 想手动指定:顶部输入电脑 IP(可带端口,如 `192.168.1.5:9527`)再点「连接」。
4. 电脑显示 6 位配对码 → 输进手机。
5. 首次配对:电脑显示二维码 → 手机「扫码」对准;同时记下电脑显示的 8 位恢复码。

之后每次连接只需「配对码 → 自动 TOTP」;掉线/重启后自动免码续连,无需重配。

## 三、操作

### 触控板(默认)

| 手势 | 效果 |
| --- | --- |
| 单指滑动 | 移动光标 |
| 单指轻点 | 左键单击 |
| 单指按住约 250ms 后移动 | 按住左键拖动 |
| 双指上下滑动 | 滚轮 |
| 双指轻点 | 右键单击 |

灵敏度用下方滑条调(0.5x ~ 3.0x)。

### 屏幕镜像

| 手势 | 效果 |
| --- | --- |
| 单指轻点 | 光标移到该点并左键单击 |
| 单指轻移 | 只移动光标(悬停) |
| 单指按住拖动 | 按住左键拖动(拖文件/框选) |
| 双指捏合 | 放大/缩小手机端画面(只影响手机) |
| 双指平移 | 平移手机端画面 |

进入屏幕模式后,底部有「键盘」按钮,点它打字即可把文本打到电脑当前焦点。

### 摄像头 / 麦克风

手机面板开启「摄像头」→ 电脑出现手机实时画面,并被识别为摄像头(供 OBS/会议软件用);开启「麦克风」同理,手机声音进入电脑。

### 中转站 / 文件互传

- 手机悬浮球「发送文件到电脑」→ 选文件 → 传到电脑中转目录(默认 `~/Downloads`);
- 手机任意 App 点「分享」→ 选「超级终端」→ 文件直传电脑;
- 电脑悬浮窗可浏览手机中转目录、点「取回」拉文件到电脑。

## 常见问题

- **连不上 / 超时**:手机和电脑同一 Wi-Fi;电脑防火墙放行 `python`(后台模式还需放行 `pythonw`)。
- **「扫描」找不到电脑**:自动发现靠局域网 UDP 广播。路由器开了「AP 隔离/访客网络」或防火墙拦 UDP 广播会扫不到 → 用顶部手动输 IP 即可。
- **动态码验证失败(时间不同步)**:把手机和电脑都设为「自动同步时间」。
- **手机重装后连不上 / 提示恢复码**:在手机点连接 → 输配对码 → 输入首次配对记下的 8 位恢复码 → 重新扫码配对。
- **想彻底重新配对**:删除电脑端 `pc-server/secret.json` 后重连,会重新走首次配对。
