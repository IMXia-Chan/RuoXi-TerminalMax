# 手机触控板 (Phone Touchpad)

把 Android 手机变成电脑的 **触控板 + 远程桌面**,通过 **Wi-Fi 局域网** 控制电脑鼠标、看电脑屏幕、往电脑里打字。

> 为什么用 Wi-Fi 而不是蓝牙:部分国产 ROM(OPPO ColorOS 等)不支持「手机伪装成蓝牙鼠标」。
> Wi-Fi 方案电脑端只需跑一个 Python 脚本,手机端是普通 App,都不涉及 root / 解锁 / 刷机,**不影响保修**。

> **只在你自己可信的 Wi-Fi 下使用。** 它能把电脑鼠标/屏幕/摄像头/麦克风交给手机——
> 权限很大,所以务必只在自家或公司可信网络里用,别在公共 Wi-Fi / 陌生热点上开。
> 配对种子、二维码、恢复码就是你的「钥匙」,**不要截图、不要发给任何人**。安全机制见「安全设计」。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 触控板 | 手机触摸控制电脑光标(移动/点击/滚轮/拖拽/右键) |
| 屏幕镜像 | 手机实时看到电脑画面(5 fps),点哪操作哪 |
| 文本输入 | 手机打字直接打到电脑当前焦点(支持中文/emoji) |
| 局部缩放 | 双指捏合放大手机端画面,**只影响手机显示,不动电脑** |
| 电脑前端 | 电脑端有图形界面,登录 PIN 保护,首次配对显示二维码 |

## 安全设计(每次连接都完整重新认证)

| 层 | 机制 |
| --- | --- |
| 电脑端登录 PIN | 打开电脑前端要先输 6 位 PIN(首次运行自己设置),防止别人在电脑上看到配对码/二维码/恢复码 |
| 动态配对码 | 手机一连上,电脑就显示一个 **6 位随机码**(每次连接都变)。输入它 = 选对这台电脑 |
| TOTP 动态码 | 配对码通过后,双方用同一把密钥 + 当前时间各自算出 6 位动态码自动校验 |
| 带外传种子 | 首次配对密钥用 **二维码** 从电脑传到手机(手机扫码,不用手动抄 32 位) |
| 一次性恢复码 | 首次配对显示一次 8 位码,手机卸载/丢失后凭它重新配对,用一次即作废 |
| 防暴力破解 | 连续 **3 次 TOTP 码错误 → 锁定**,时长指数翻倍:30s → 60s → 120s → 240s… |
| 空闲超时 | 控制模式 **60 秒**无操作自动断开 |
| 本地加密 | 密钥、恢复码用 Windows **DPAPI** 加密落盘(绑定当前 Windows 账户),不存明文 |
| 防伪造/重放 | 每条控制指令带 HMAC-SHA256 签名 + 递增序号,防篡改、防重放 |

**不需要 SMTP 邮箱和授权码** —— 全程局域网 + 本地密钥,不依赖发信服务。

## 目录结构

```
phone-touchpad/
├── pc-server/
│   ├── server.py      # 电脑端服务(认证 + TOTP + 鼠标/屏幕/文本)
│   ├── secret.json    # 首次配对时生成(种子+恢复码,DPAPI 加密)
│   └── master.json    # 登录 PIN 校验值(首次运行设置时生成)
└── app/               # Android App(Android Studio 工程)
```

## 一、电脑端

1. 装 Python 3(没有就去 [python.org](https://www.python.org),装时勾选 Add to PATH)。
2. 装两个可选依赖(二维码 + 屏幕抓取):
   ```bash
   pip install segno pillow
   ```
   - 没装 `segno`:二维码不显示,退化成手动抄 32 位种子,其余功能正常。
   - 没装 `pillow`(Pillow):屏幕镜像功能不可用,触控板/文本输入仍正常。
3. 运行:
   ```bash
   python pc-server/server.py
   ```
   首次运行会让你 **设置 6 位登录 PIN**,之后每次打开都要输这个 PIN 才能进控制面板。

   > Windows 下若检测到不是管理员,脚本会自动申请一次提权(弹 UAC,点「是」)。
   > **建议以管理员身份运行**:否则手机控制不了那些以管理员权限打开的窗口(如联想电脑管家、部分系统设置/弹窗)——这是 Windows 的权限隔离(UIPI)机制,不是 bug。
4. 界面顶部会显示 **本机地址 `IP:9527`**,手机端填这个 IP。

> 用 `ipconfig` 也能查本机 IPv4(通常是 `192.168.x.x`)。
> 纯命令行环境可用 `python pc-server/server.py --no-gui`(会弹系统消息框代替前端)。

## 二、手机端

1. 用 Android Studio 打开工程根目录 `phone-touchpad`,连手机点 `Run` 安装(或用 `gradlew assembleDebug` 打 APK)。
2. 手机和电脑连 **同一个 Wi-Fi**。
3. 打开 App → 点 **「扫描」** 自动发现电脑(电脑端会 UDP 自动广播,**不用手输 IP**)→ 找到后自动连上。
   > 想手动指定:顶部输入电脑 IP(可带端口,如 `192.168.1.5:9527`)再点「连接」。
4. 电脑端显示 **6 位配对码** → 输进手机。
5. **首次配对**:电脑端显示二维码 → 手机点「扫码」对准二维码(也保留「手动输入」兜底);同时电脑端显示 **8 位恢复码,请记下来**。
6. 手机自动算 TOTP 动态码并验证 → 状态显示「已连接」。

之后每次连接只需「配对码 → 自动 TOTP」两步;只有手机重装/换手机才需要用恢复码重新配对。

## 三、操作

### 触控板模式(默认)

| 手势 | 效果 |
| --- | --- |
| 单指滑动 | 移动光标 |
| 单指轻点 | 左键单击 |
| 单指按住约 250ms 后移动 | 按住左键拖动 |
| 双指上下滑动 | 滚轮 |
| 双指轻点 | 右键单击 |

灵敏度用下方滑条调(0.5x ~ 3.0x)。

### 屏幕镜像模式(点「切换:屏幕」)

| 手势 | 效果 |
| --- | --- |
| 单指轻点 | 移动光标到该点并左键单击 |
| 单指轻移 | 只移动光标(悬停) |
| 单指按住拖动 | 按住左键拖动(拖文件/框选) |
| 双指捏合 | 放大/缩小手机端画面(只影响手机) |
| 双指平移 | 平移手机端画面 |

进入屏幕模式后,底部会出现「键盘」按钮,点它打字即可把文本打到电脑当前焦点。

## 四、验证方法

1. 电脑端 `python pc-server/server.py` → 设 PIN → 登录 → 显示 IP/端口。
2. 手机输 IP 连接 → 电脑弹配对码 → 手机输对 → 首次配对扫码 → 自动 TOTP → 「已连接」。
3. 单指滑动,电脑光标跟随;轻点=左键;双指滑=滚轮。
4. 点「切换:屏幕」→ 手机出现电脑画面 → 点哪电脑鼠标点哪;点「键盘」打字进电脑。
5. 反向验证:故意输错配对码被拒;连续输错 TOTP 触发锁定(30s 起)。

## 常见问题

- **连不上 / 超时**:手机和电脑同一 Wi-Fi;电脑防火墙放行 `python` 或临时关掉再试。
- **「扫描」找不到电脑**:自动发现靠局域网 UDP 广播。若路由器开了「AP 隔离 / 访客网络隔离」或防火墙拦了 UDP 广播,会扫不到 —— 这时用顶部手动输 IP 即可(电脑端界面会显示本机 IP)。
- **动态码验证失败(时间不同步)**:TOTP 依赖两端时间一致,把手机和电脑都设为「自动同步时间」。
- **手机重装后连不上 / 提示恢复码**:手机本地密钥没了,电脑端又是「已配对」状态。在手机点连接 → 输配对码 → 电脑显示「已配对」时,手机弹「输入恢复码」→ 输入首次配对记下的 8 位恢复码 → 重新扫码配对。
- **想彻底重新配对**:删除电脑端 `pc-server/secret.json` 后重连,会重新走首次配对(生成新的种子 + 新恢复码)。
- **触发锁定**:连续 3 次 TOTP 错误会锁定,时长逐次翻倍(30s/60s/120s…),等倒计时结束再连。
- **屏幕模式没画面**:确认电脑端装了 Pillow(`pip install pillow`),且手机已点「切换:屏幕」。
- **光标方向反了**:改 `TouchpadView.kt` 的 `ACTION_MOVE` 分支里 `sy` 取负号。
